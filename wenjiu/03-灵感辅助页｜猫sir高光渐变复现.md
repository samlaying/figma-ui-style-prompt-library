## 一、复现目标

复现教程中的深色高光卡片：深色基准面、蓝色内阴影、底部蓝光、白蓝弱高光、渐变描边、轮廓光带和低透明度网格纹理。

## 三、复现参数

| 层级 | 设置 |
|---|---|
| 卡片底色 | `#0E1730`，带轻微蓝相，不使用纯黑 |
| 外描边 | 蓝白渐变，2 px |
| 内阴影 1 | 蓝色，X 0 / Y 0 / Blur 20 |
| 内阴影 2 | 浅蓝色，X 0 / Y -18 / Blur 30 |
| 底部发光 | 蓝色径向渐变 + Layer Blur 80 |
| 轮廓光带 | 蓝色线性渐变 + Layer Blur 50 |
| 白蓝高光 | 白色到透明的线性渐变 + Layer Blur 10 |
| 网格纹理 | 1 px 线条，整体透明度约 16% |

## 四、复现步骤

1. 创建深色矩形或 Frame，设置圆角 32 px。
2. 添加 2 px 蓝白渐变描边。
3. 添加蓝色 `INNER_SHADOW`，Y 为 0、Blur 为 20。
4. 复制一层蓝色发光形状，设置向上的内阴影和更大的模糊值。
5. 在卡片底部放置蓝色径向渐变椭圆，添加 Layer Blur 80。
6. 用一个倾斜的渐变矩形模拟流动光带，添加 Layer Blur 50。
7. 使用白蓝渐变制作一条弱高光，透明度保持较低。
8. 用重复的 1 px 横线与竖线组成网格，整体透明度控制在 10%–20%。
9. 将文字放在高光之上，保持主标题与 CTA 的对比度。

## 五、与夜航项目的连接

这不是直接把高光效果铺到所有页面，而是作为夜航 NITEWALK 的 **P1 灵感模块**：

- 可用于“漫游进行中”的沉浸状态卡片。
- 可用于声音详情页的播放器容器。
- 可用于活动页 / 会员页的高级视觉区。
- P2 只保留一条光带或一圈渐变描边。
- P3 不使用高光渐变，保持功能界面清晰。

核心原则：高光是空间层级和品牌氛围，不是装饰堆叠。每个页面最多保留一个主要发光区域。
