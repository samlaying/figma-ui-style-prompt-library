# 第二讲：UI 设计中的色彩搭配与实用方法论

> 对应课程文件：02_2025-12-10 230802
>
> 项目：夜航 NITEWALK —— 城市夜间情绪漫游 App

## 一、本讲作业结论

本项目最终收敛为 **3D + 柔雾弥散风**，采用“暖白底 + 薰衣草蓝紫 + 蜜桃粉”的双色体系。薄荷绿、奶油黄仅作为备选探索色，不进入正式 UI。

选择理由：

1. **品牌差异性**：不使用深色霓虹疗愈套路，用蓝紫建立数字感，用蜜桃粉建立温度。
2. **用户调性契合**：目标用户需要“被安抚但不幼稚”的陪伴，双色比多色更安静、更成熟。
3. **世界观可延展**：月相、城市光线、声音波纹都可以在蓝紫与蜜桃之间变化，不需要不断增加新颜色。
4. **功能可读性**：彩色只承担品牌、行动和情绪标签，中性色负责承载信息。

## 二、视觉风格选择

| 维度 | 夜航 NITEWALK 的选择 |
|---|---|
| 风格 | 3D + 柔雾弥散风 |
| 图形 | 3D 软体月相、彩色弥散、声音波纹、圆形情绪球 |
| 色彩 | 暖白底，薰衣草蓝紫主导，蜜桃粉作为唯一强调色 |
| 形状 | 16 pt 卡片圆角、24 pt 输入框与胶囊按钮 |
| 材质 | 高强度 Layer Blur、低透明渐变、轻微噪点、柔和高光 |
| 氛围 | 轻盈、温暖、通透、安静，不做深夜霓虹 |

### 为什么不选其他风格

- **不选 3D 大眼怪**：趣味性太强，容易让情绪疗愈产品变得幼稚。
- **不选 3D 潮流黑底**：容易落入霓虹、游戏化和“科技感模板”的套路。
- **不选 2D 卡漫线描**：信息层级和材质表现力不足，不利于打造 P1 核心视觉页。

## 三、作业一：品牌色与中性色阶

### 3.1 品牌主色与辅助色

| 色彩角色 | 色值 | 选择理由 | 使用范围 |
|---|---|---|---|
| **品牌主色：Lavender Blue** | `#8B95F2` | 延续 README 的品牌基线，传达智慧、柔和与数字感 | 品牌图形、选中态、P1 核心视觉 |
| **强调色：Peach Pink** | `#F7A8A0` | 提供温度和陪伴感，比高饱和橙色更高级 | CTA、情绪标签、重要反馈 |
| **主色浅阶：Soft Lavender** | `#EEF0FF` | 主色的低对比明度变化 | 页面底板、推荐卡、弥散背景 |
| **强调色浅阶：Soft Peach** | `#FFF0ED` | 强调色的低对比明度变化 | CTA 背景、提示底板、情绪标签 |

### 3.2 颜色比例

```text
暖白与中性色                  70%
Lavender Blue                 20%
Peach Pink                    10%
```

控制原则：薰衣草蓝紫负责品牌识别，蜜桃粉负责行动反馈，所有其他颜色只作为这两种颜色的浅阶或透明渐变。这样保留双色碰撞，又不会让页面变成多色噪音。

### 3.3 五个中性色阶

| 色阶 | 色值 | 用途 |
|---|---|---|
| ① 页面背景 | `#F6F7FA` | P2 / P3 页面背景；比纯白更容易制造卡片层次 |
| ② 卡片背景 | `#FFFFFF` | 内容卡片、输入区、路线信息卡 |
| ③ 辅助文字 | `#8D96B3` | 时间、来源、提示、弱状态文字 |
| ④ 深灰文字 | `#4A526B` | 正文、说明、次级标题 |
| ⑤ 核心文字 | `#111522` | 页面标题、核心数据、重要操作文字 |

页面统一使用暖白或浅薰衣草背景；核心文字使用 `#2E3147`，辅助文字使用 `#7B8096`。只有极少数沉浸式状态卡片使用深蓝灰 `#3D426A`，避免大面积黑色。

## 四、作业二：参考图的「色形字质」拆解

### 参考对象

本项目参考 **Apple Liquid Glass 系统视觉 + Google Material 3 Expressive 的表达性设计**，并以 Headspace、AllTrails 等产品作为功能信息架构参考。Apple 强调分层材质、内容优先、动态适配与可访问性降级；Google 强调情绪化表达、动态色彩、对比形状和有意图的动效。

参考来源：[Apple WWDC26 Design Guide](https://developer.apple.com/wwdc26/guides/design/)｜[Adopting Liquid Glass](https://msc-kobol-public-prod.apple.com/documentation/technologyoverviews/adopting-liquid-glass)｜[Google Expressive Design Research](https://design.google/library/expressive-material-design-google-research?pubDate=20250521)

### 4.1 色（Color）

- 主色倾向深蓝黑，用于营造夜间空间和内容对比。
- 视觉主体使用暖黄色，模拟月光，成为品牌记忆点。
- 行动色使用珊瑚橙，面积小但对比强，帮助用户识别下一步行动。
- 浅薰衣草和浅蜜桃只承担背景与标签作用，不新增第三个彩色家族。
- 彩色总数控制为 3 个核心彩色：月光黄、珊瑚橙、雾蓝；蓝黑属于品牌中性色。

### 4.2 形（Shape）

- P1 使用大圆形和大圆角，强化月相、情绪球和玻璃容器的柔和感。
- 主要卡片圆角 22 pt，按钮圆角 26–28 pt。
- P3 降低圆角到 12–16 pt，减少“玩具感”，让表单与隐私设置更专业。
- 选中态使用珊瑚橙色块或月光黄短线，不使用复杂装饰性图标。
- 线条尽量少而细，避免与 3D 主体争夺注意力。

### 4.3 字（Typography）

- 中文：PingFang SC，保证移动端阅读清晰。
- 英文与数字：SF Pro Text / SF Pro Display，保持英文、数字、时间的统一性。
- P1 标题使用较大字号和短句，强调情绪；P2 / P3 使用更紧凑的信息层级。
- 英文和数字不混用多种字体；仅在品牌海报或特殊活动页中使用展示字体。

### 4.4 质（Texture）

- 3D 月相：使用哑光球体、柔和明暗和少量边缘光，不使用高反光金属。
- 玻璃卡片：白色低透明度 + 背景模糊 + 细描边；只用于 P1 / P2。
- 地图与声音卡片：使用低对比渐变和波纹，帮助用户感知“空间”和“声音”。
- P3 去掉玻璃和强光效，恢复纯色、平面和清晰分割。

## 五、作业三：两张页面铺色记录

### 页面一：01 开屏 / 情绪引导（P1）

#### 铺色步骤

1. **中性色阶**：页面底色使用 `#FAFBFE`，顶部叠加薰衣草、薄荷、奶油黄的彩色弥散。
2. **创意图形**：将圆形月相改为 `#8B95F2` 与 `#F9E4A7` 的柔和 3D 主体。
3. **大色块**：大面积保持暖白与浅薰衣草，不再使用深蓝黑铺底。
4. **小亮点**：CTA 使用 `#F7A8A0`，标题使用 `#2E3147`，辅助信息使用 `#7B8096`。

#### 页面配色结果

| 元素 | 配色 |
|---|---|
| 页面背景 | `#FAFBFE` |
| 月相主体 | `#8B95F2` → `#F7A8A0` |
| 主标题 | `#2E3147` |
| 辅助文字 | `#7B8096` |
| CTA | `#F7A8A0` |

#### 视觉判断

页面只保留“月相”和“开始漫游”两个视觉重点，符合“大亮点不超过 2 个”的规则。用户第一眼先看到月相，第二眼看到 CTA，品牌氛围和任务入口均明确。

### 页面二：02 今晚首页（P1）

#### 铺色步骤

1. **中性色阶**：使用 `#FAFBFE` 作为页面背景，卡片使用 `#FFFFFF`。
2. **创意图形**：放入放空 / 散步 / 听风三个情绪球，分别以薰衣草蓝紫、薄荷绿、蜜桃粉区分。
3. **大色块**：推荐卡使用 `#EEF0FF`，叠加一层极淡的彩色弥散。
4. **小亮点**：推荐 CTA 使用 `#F7A8A0`；状态文案使用 `#7B8096`。

#### 视觉判断

三个情绪球承担“金刚位”作用，每个球的主色不同，用户可以快速区分状态。推荐卡只保留一个主行动，避免首页出现多个同等强度的按钮。

## 八、本讲小结

夜航 NITEWALK 的色彩不是单纯追求“好看”，而是把颜色分配给不同任务：蓝黑建立夜间世界观，月光黄建立品牌记忆，珊瑚橙提示行动，雾蓝缓冲信息层级。最终通过“中性色阶 → 创意图形 → P1 大色块 → 小亮点”的顺序完成页面铺色，让视觉表达与用户任务保持一致。

> **修订说明：** 根据品牌基线与课程新增要求，本项目最终不再使用深蓝黑作为大面积主底，而改为“暖白中性底 + 彩色弥散渐变 + 少量高亮行动色”。

## 九、最终弥散渐变规范

### 9.1 60 / 30 / 10 页面比例

| 比例 | 内容 | 夜航最终方案 |
|---:|---|---|
| 60% | 背景与阅读容器 | `#FAFBFE`、`#F7F8FA`、`#FFFFFF` |
| 30% | 辅助结构与情绪底板 | `#EEF0FF`、`#EAF8F2`、`#FFF0ED` |
| 10% | CTA、选中态、主图形高光 | `#8B95F2`、`#F7A8A0`、`#F9E4A7` |

### 9.2 彩色弥散层

P1 页面不再使用单一纯色圆形，而是使用 3–4 个彼此有透明过渡的圆形：

```text
Lavender Blob：#8B95F2 → 透明
Peach Blob：    #F7A8A0 → 透明
```

建议参数：

- 圆形数量：3–4 个
- Layer Blur：200–300
- 单个圆形透明度：55%–80%
- 圆形之间避免硬边相交
- 文字区域保持至少 60% 的低干扰留白
- 不叠加黑色阴影；如需层次，使用蓝紫色低透明度阴影

### 9.3 P1 月相主体渐变

月相主体使用径向渐变：

```text
中心：#F7A8A0
中段：#E5DDFB
边缘：#8B95F2
```

这样既保留“月光”的暖感，又与品牌蓝紫建立联系，不会出现单一黄色圆形像占位图的问题。

### 9.4 最终视觉红线

- 不使用整屏纯黑或深蓝黑作为默认背景。
- 不把 5 个品牌色全部等面积放进一个页面。
- 不使用高饱和荧光色作为大面积色块。
- 不让渐变覆盖标题、正文和 CTA 的可读区域。
- P1 可以有弥散和高光；P2 只保留局部弥散；P3 回到中性底和功能色。
