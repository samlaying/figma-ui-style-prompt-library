# 八阶段设计工作流：夜航 NITEWALK 项目分析

> 项目：夜航 NITEWALK —— 城市夜间情绪漫游 App
>
> 分析目的：将课程中的八阶段设计方法落到当前项目，明确“已经完成什么、哪里不够、下一步怎么做”。

## 一、项目总览

### 一句话定位

夜航 NITEWALK 是一个帮助城市独居青年在夜间通过短时路线、声音陪伴和低压力记录获得情绪缓冲的移动端产品。

### 核心用户

- 下班后脑内过载、不想立刻刷短视频的独居青年。
- 需要城市灵感、声音和安静路线的夜间创作者。
- 想轻社交但不想经营公开人设的弱关系用户。

### 核心主链路

```text
选择今晚状态 → 获取个性化方案 → 查看路线 / 声音 → 开始漫游 → 留下一句夜记 → 复盘与收藏
```

### 当前视觉决策

- 主风格：3D + 柔雾弥散 + 局部高光。
- 主色：薰衣草蓝紫 `#8B95F2`。
- 强调色：蜜桃粉 `#F7A8A0`。
- 中性底：`#FAFBFE` / `#FFFFFF`。
- P1：彩色弥散、3D 主体、高光渐变。
- P2：局部渐变和卡片质感。
- P3：中性色、表单和安全信息降噪。

## 二、八阶段总链路

```text
① 定位调研 → ② 信息架构 → ③ 色彩系统 → ④ 创意图形
       ↓                                  ↓
⑧ 视觉规范 ← ⑦ 动效 ← ⑥ 3D 资产 ← ⑤ 核心组件
```

前四阶段负责定义方向，后四阶段负责把方向变成可以复用和交付的视觉系统。当前项目已经有定位、12 页原型和初步配色，但仍需要把创意图形、组件、3D 资产和规范真正收敛起来。

## 三、阶段一：定位与调研

### 当前判断

项目选题成立，因为它同时具备情绪价值、城市生活方式和视觉表达空间；但“夜间漫游”仍然偏宽，需要通过真实场景把产品边界收紧。

### 执行清单

| 动作 | 当前产出 | 当前问题 | 下一步 |
|---|---|---|---|
| 项目定位 | 一句话定位、核心用户、主链路 | 用户的具体夜间触发场景还不够具体 | 补 3 个用户场景：加班后、失眠时、灵感枯竭时 |
| 选题评估 | 路线、声音、夜记、轻社交 | 功能容易膨胀成“夜间生活平台” | 首版只保留状态、方案、漫游、夜记 |
| Moodboard | 柔雾弥散、高光渐变、蓝紫蜜桃 | 参考图需要提炼共性，不只是收藏 | 归纳为：柔雾、悬浮、弱社交、夜间陪伴 |
| 竞品分析 | Headspace、AllTrails、Strava、Komoot 等 | 竞品功能多，容易照搬 | 只提取主链路与组件，不复制产品定位 |

### 阶段验收标准

别人能在 10 秒内回答：这是给谁用的、什么时候用、为什么不用普通地图或冥想 App。

## 四、阶段二：信息架构与原型骨架

### 当前 12 页结构

| 等级 | 页面 |
|---|---|
| P1 | 开屏、今晚首页、漫游进行中、我的月相 |
| P2 | 路线详情、声音详情、发现 Feed、夜记发布、漫游反馈 |
| P3 | 搜索筛选、我的记录、隐私安全 |

### 当前判断

12 页已经能够覆盖从进入产品到完成一次漫游的完整链路，但“发现 Feed”和“搜索筛选”在首版中不是核心，应避免抢走首页与漫游页的视觉资源。

### 下一步动作

1. 画出 IA 图，明确首页、发现、记录、我的四个 Tab 的入口关系。
2. 把核心任务压缩为 3 步：选状态 → 开始方案 → 结束记录。
3. 补充异常路径：没有定位权限、路线中途退出、声音加载失败。
4. 用 375 × 812 pt 统一检查 4 px / 8 px 栅格和 44 pt 点击热区。

### 阶段验收标准

用户不看视觉装饰，也能理解页面层级；核心功能三步内可达。

## 五、阶段三：色彩系统

### 最终色彩策略

本项目已经从多色 Pastel 调整为更克制的双色体系：

| 类型 | Token | 色值 | 用途 |
|---|---|---|---|
| 主色 | `Color/Primary` | `#8B95F2` | 品牌识别、选中态、主图形 |
| 强调色 | `Color/Accent` | `#F7A8A0` | CTA、行动反馈、情绪标签 |
| 主色浅阶 | `Color/PrimarySoft` | `#EEF0FF` | 卡片、浅色弥散底 |
| 强调浅阶 | `Color/AccentSoft` | `#FFF0ED` | CTA 背景、提示底板 |
| 页面底 | `Neutral/100` | `#FAFBFE` | 页面大面积底色 |
| 卡片底 | `Neutral/000` | `#FFFFFF` | 内容容器 |
| 主文字 | `Neutral/900` | `#2E3147` | 标题、核心信息 |
| 辅助文字 | `Neutral/600` | `#7B8096` | 弱信息、时间、来源 |

### 60 / 30 / 10

```text
70% 中性背景与卡片
20% 薰衣草蓝紫
10% 蜜桃粉
```

这里不再追求“每个页面都多彩”，而是让主色和强调色承担品牌和行为含义，其余颜色只做明度变化。

### 合规检查

- 正文优先使用 `#2E3147`，不使用浅灰文字配白底。
- CTA 不使用白字配浅蜜桃底；浅色按钮使用深蓝灰文字。
- 暗色高光卡片使用 `#0E1730`，不使用纯黑 `#000000`。

## 六、阶段四：创意图形

### 核心视觉隐喻

**“一轮月相穿过城市的柔雾，留下可以跟随的光。”**

### 图形系统

| 图形 | 视觉作用 | 应用位置 |
|---|---|---|
| 彩色弥散 Blob | 建立空气感和情绪氛围 | P1 背景、空状态 |
| 双色渐变月相 | 建立品牌记忆点 | 开屏、个人月相 |
| 声音波纹 | 把不可见的声音视觉化 | 声音详情、漫游中 |
| 高光渐变卡片 | 表达沉浸、悬浮和高级感 | 漫游中、会员 / 活动卡 |
| 路线轨迹 | 连接空间与行动 | 路线详情、漫游进度 |

### 当前已完成

- 已在 Figma 辅助页复现蓝色内阴影、底部发光、渐变描边、光带和网格纹理。
- 已在 P1 页面加入蓝紫 + 蜜桃双色弥散。

### 下一步动作

1. 从月相、波纹、路线轨迹中选一个作为主 IP，不要三个同时抢主视觉。
2. 以圆形、弧线和柔和破型为共同几何语言。
3. 背景 Blob 透明度控制在 8%–25%，不覆盖标题和 CTA。
4. 每个 P1 页面最多 2 个大视觉亮点。

## 七、阶段五：核心组件

### 组件优先级

1. 主按钮 / 次按钮 / 胶囊标签。
2. 情绪选择球。
3. 路线信息卡。
4. 声音播放器卡。
5. 漫游进度卡。
6. Tab Bar。
7. 隐私设置行和 Toggle。

### 组件质感规则

- 普通卡片：白底、16 px 圆角、低透明蓝紫阴影。
- P1 高光卡片：深蓝相底、渐变描边、双色内阴影、单条光带。
- P3 功能卡片：白底、浅边框、无高光、无强渐变。
- 所有组件内边距至少 16 px，大卡片内边距 20–24 px。

### 当前缺口

目前 Figma 中主要是页面骨架和视觉样例，还没有真正建立组件 Variants。下一步应该先建立 Button、Card、Chip、Tab Bar 四类组件，再回填页面。

## 八、阶段六：3D / AIGC 资产

### 首版资产范围

不建议一开始制作大量 3D 资产，只做 3 个：

- 月相主体：品牌识别资产。
- 声音波纹球：声音详情资产。
- 漫游光标：路线进行中资产。

### 资产原则

- 形体简单，避免复杂写实模型。
- 材质统一：哑光软体 + 局部玻璃高光。
- 光线统一：冷蓝环境光 + 蜜桃边缘光。
- 资产必须能导出透明 PNG 或 SVG / Lottie，不只停留在视觉稿里。

### 降级方案

如果时间有限，用 Figma 基础形状 + 径向渐变 + Layer Blur 做 2.5D 资产，不从零学习 Blender。

## 九、阶段七：动效

### 只做四个高价值动效

| 节点 | 动效 | 参数建议 |
|---|---|---|
| 开屏 | Blob 与月相缓慢出现 | 1.2–1.8 s |
| 状态选择 | 情绪球轻微放大并出现光晕 | 220–360 ms |
| 漫游中 | 底部光带呼吸 | 4–6 s 循环 |
| 夜记保存 | 卡片收缩、月相亮起 | 360–480 ms |

### 动效原则

- 动效服务于“陪伴”和“呼吸”，不做快速炫技。
- P3 页面只保留必要状态反馈。
- 所有动效提供减少动效的降级状态。

## 十、阶段八：视觉语言规范

### 需要最终沉淀的六类规范

1. **品牌心智**：蓝紫是夜间陪伴，蜜桃是行动和温度。
2. **色彩系统**：双色主体系 + 中性色阶 + 状态色。
3. **字体阶梯**：Display 28–32、H1 22–24、H2 18–20、Body 14–16、Caption 12。
4. **栅格间距**：4 px 基础单位，8 / 12 / 16 / 24 / 32 间距。
5. **质感规范**：普通卡片、高光卡片、功能卡片三种质感等级。
6. **组件库**：Button、Card、Chip、Tab Bar、Input、Toggle 六类基础组件。

### 当前项目的关键收敛规则

```text
P1：可以发光，但最多两个大亮点
P2：可以有局部渐变，但内容优先
P3：不做氛围装饰，保证效率与可读性
```

| P2 | 建立完整视觉语言规范页 | 本文已完成初稿 |

## 十二、最终判断

这个项目现在最需要的不是继续增加颜色、材质或页面，而是完成三次收敛：

1. **颜色收敛**：只保留蓝紫 + 蜜桃，其他颜色降级为中性色或透明渐变。
2. **图形收敛**：月相作为主 IP，波纹和路线轨迹作为辅助语言。
3. **组件收敛**：先把 Button、Card、Tab Bar 做成可复用组件，再扩展到 12 个页面。

如果这三步完成，项目会从“有一些好看的效果”进入“有明确视觉系统的产品设计”。
