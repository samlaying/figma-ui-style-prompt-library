## 品牌视觉基线

- 主色：薰衣草蓝紫 `#8B95F2`
- 强调色：蜜桃粉 `#F7A8A0`
- 辅助色：薄荷绿 `#A8E6CF`、薰衣草 `#C4B5F7`、奶油黄 `#F9E4A7`
- 页面底色：`#FAFBFE`
- 文字最深色：`#2A2A34`
- 字体：思源黑体 / Noto Sans SC + Plus Jakarta Sans
- 圆角：卡片 16px 为主，输入框和胶囊按钮可使用 24px
- 图标：线性、1.5px、圆头
- 阴影：使用低透明度的品牌蓝紫阴影，避免纯黑重阴影

## 01. 彩色弥散效果

### 视觉风格

柔和、通透、低对比，像春天早晨的光。多个色块经过高强度模糊后融合成背景氛围，不承担主要信息，只负责建立情绪和层次。

### Figma 画板

- 名称：`彩色弥散效果 · Color Diffusion`
- 节点：`58:2`
- 典型应用：Hero 背景、Banner 顶部、空状态背景、头像光晕

### 绘制方法

1. 创建一个非纯白的浅色背景，建议使用 `#FAFBFE` 或 `#F3F4FE`。
2. 绘制 4–6 个大小不同、位置错落的圆形。
3. 使用主色和辅助色，例如 `#8B95F2`、`#C4B5F7`、`#A8E6CF`、`#F9E4A7`。
4. 控制颜色之间的色差，不要同时放入多个高饱和色。
5. 统一添加 `Layer Blur`，建议从 200–300 开始调整。
6. 如果需要颗粒感，叠加等大的噪点层，设置 `Soft Light`，透明度约 30%–50%。

### 可复用绘制提示词

```text
在页面顶部制作一块轻盈的彩色弥散背景。以 #FAFBFE 为底色，错落放置 4–6 个大小不同的圆形，使用 #8B95F2、#C4B5F7、#A8E6CF、#F9E4A7 等低饱和 pastel 色。所有圆形添加 200–300 的 Layer Blur，使颜色自然融合；可选叠加 30%–50% 透明度的 Noise，并设置 Soft Light。整体保持低对比、通透、温暖，不要出现硬边和高饱和色块。
```

## 02. 彩色弥散效果 · 5 Variations

### 视觉风格

同一弥散技法的五种情绪探索：彩虹柔和、蓝紫科技、蜜桃暖阳、薄荷成长、极简雾化。变化来自色板和构图密度，而不是复杂的结构。

### Figma 画板

- 名称：`彩色弥散效果 · 5 Variations`
- 节点：`60:2`
- 典型应用：品牌探索、主题切换、首页背景方案对比

### 绘制方法

1. 先固定圆形数量、模糊值和透明度，建立统一实验模板。
2. 每个版本只替换色板和圆形位置，保证对比有效。
3. 蓝紫版以 `#8B95F2`、`#C4B5F7` 为主。
4. 蜜桃版以 `#F7A8A0`、`#F9E4A7` 为主。
5. 薄荷版以 `#A8E6CF`、`#6DD4A0` 为主。
6. 极简版减少色块数量和色差，保留大面积留白。

### 可复用绘制提示词

```text
基于同一套彩色弥散背景模板生成 5 个视觉变体：1）彩虹柔和版；2）蓝紫科技版；3）蜜桃暖阳版；4）薄荷成长版；5）极简雾化版。所有版本保持相同画布、圆形数量、Layer Blur 200–300 和低透明度，仅替换 pastel 色板与圆形位置。颜色需要柔和、低饱和、彼此协调，避免明显的硬边和强烈渐变断层。
```

## 03. 边缘折角效果

### 视觉风格

几何、轻巧、具有纸张翻折感。直线版更利落，圆角过渡版更柔和，适合在卡片或标签角落制造识别点。

### Figma 画板

- 名称：`边缘折角效果 · Edge Fold`
- 节点：`62:2`
- 典型应用：卡片角标、提示标签、优惠券、纸张式信息块

### 绘制方法

1. 绘制卡片主体矩形。
2. 使用钢笔工具绘制连接到边缘的折角三角形。
3. 确认三角形和主体完全连接，关闭不需要的描边。
4. 使用 `Union` 合并两个图形，再执行 `Flatten`。
5. 直线版只保留必要的圆角；圆角版在转折处增加内凹锚点。
6. 对内外层的折角同步设置圆角，避免出现一层突出或断裂。

### 可复用绘制提示词

```text
制作一个轻盈的卡片边缘折角效果。先创建圆角矩形主体，再用钢笔工具绘制从右下角翻起的三角折角；使用 Union 合并并 Flatten 成单一路径。直线版保持折线利落；圆角版在折线转折处添加对称的内凹锚点，并设置约 4px 圆角，让翻折边缘出现柔和弧线。整体使用浅色背景、低对比阴影和 16px 卡片圆角。
```

## 04. 卡片高光效果

### 视觉风格

深色背景上的边缘发光和表面材质，具有高级、科技、玻璃或金属质感。高光应该克制，避免变成强烈霓虹效果。

### Figma 画板

- 名称：`卡片高光效果 · Card Highlights`
- 节点：`63:2`
- 典型应用：会员卡、数据卡片、产品展示卡、深色模式浮层

### 绘制方法

1. 使用深色卡片背景，避免在纯白背景上制作高光。
2. 给卡片描边设置多色标渐变，两侧保留浅色，中间插入透明度更低的色标。
3. 金属版：加入纹理素材，使用 `Overlay` 或 `Soft Light`。
4. 流光版：使用钢笔或椭圆绘制多个模糊形状，改变方向、透明度和渐变色。
5. 镜面版：绘制斜切路径，填充低透明度白色线性渐变。
6. 阴影和 Glow 使用品牌蓝紫，透明度保持很低。

### 可复用绘制提示词

```text
在深色背景上制作三张卡片高光示例：金属质感、流光质感、镜面质感。卡片使用深色底和多色标渐变描边，边缘高光保持低透明度。金属版叠加纹理并使用 Overlay 或 Soft Light；流光版叠加多个不同方向的模糊渐变形状；镜面版使用斜切路径和低透明度白色渐变模拟反射。整体高光克制、柔和，使用蓝紫品牌光晕，不要使用纯黑硬阴影。
```

## 05. 内容渐隐效果

### 视觉风格

让内容在边缘自然消失，避免硬裁切。视觉上干净、通透，适合滚动内容和 Banner 的边缘过渡。

### Figma 画板

- 名称：`内容渐隐效果 · Content Fade`
- 节点：`66:2`
- 典型应用：横向滚动列表、Banner 底部、Tab 栏边缘、毛玻璃内容层

### 绘制方法

#### 透明渐变遮罩

1. 在内容上方绘制矩形。
2. 将矩形颜色设置为与背景完全一致。
3. 使用同色线性渐变，只改变两端透明度。
4. 需要背景模糊时，在遮罩上添加 `Background Blur`。

#### 透明渐变蒙版

1. 绘制覆盖内容区域的几何图形。
2. 将几何图形设置为透明度渐变。
3. 与内容一起执行 `Use Mask`。
4. 蒙版只对 Alpha 有反应，颜色本身不影响显示。

### 遮罩与蒙版的选择

| 需求 | 推荐方式 |
| --- | --- |
| 需要 Background Blur | 透明渐变遮罩 |
| 只需要内容透明渐隐 | 透明渐变蒙版 |
| 需要背景色融入 | 遮罩颜色必须匹配背景 |

### 可复用绘制提示词

```text
制作一个内容渐隐效果示例，展示透明渐变遮罩和透明渐变蒙版两种方案。左侧使用与背景同色的渐变矩形覆盖 Banner 底部，并让透明度从 0% 平滑过渡到 100%，同时添加轻微 Background Blur；右侧使用透明度渐变几何图形作为蒙版裁切内容。整体边缘要柔和、自然、无硬切，使用 #FAFBFE 和 #F3F4FE 作为温暖的蓝白背景。
```

### 动态按钮设计 · Smart Animate

原方案包含 6 个状态：初始、文字隐藏、进度开始、进度完成、勾选放大、勾选回弹。原型链路为 `On Click` 启动，后续 `After Delay + Smart Animate`。

### 网页载入动画 · Wave Loading

原方案包含 4 个状态：波浪低位、波浪充满圆形、波浪溢出全屏、最终网页。原型链路为 2000ms、1000ms、1000ms 的 `After Delay + Smart Animate`。
