## 品牌基线

- 主色：`#8B95F2`
- 强调色：`#F7A8A0`
- 辅助色：`#A8E6CF`、`#C4B5F7`、`#F9E4A7`
- 页面底色：`#FAFBFE`
- 字体：思源黑体 / Noto Sans SC + Plus Jakarta Sans
- 圆角：卡片 16px；输入框和胶囊按钮 24px
- 图标：线性 1.5px、圆头
- 阴影：低透明度品牌蓝紫阴影，避免纯黑重阴影
